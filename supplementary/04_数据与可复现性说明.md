# 数据与可复现性说明

> 对应论文 3.2 节「数据来源与样本筛选」。本文件同时说明本仓库**公开了什么、未公开什么**，避免读者对可得性产生误解。

## 一、数据来源

研究数据均来自**抖音公开短视频平台**，通过合规数据采集方式获取公开非涉密数据。

| 模块 | 内容 |
| --- | --- |
| 文本数据 | 短视频全部用户公开评论内容 |
| 结构化数据 | 对应视频的点赞量、评论量、转发量、视频时长、视频分类 |

## 二、样本筛选口径

| 环节 | 口径 |
| --- | --- |
| 抽样范围 | 生活、美食、娱乐三大大众关注度最高的短视频类别 |
| 随机采集 | **420** 条短视频样本，每条视频抓取全部有效评论 |
| 预处理剔除 | 剔除字数过少、无实际语义的无效评论 |
| **最终有效样本** | **406** 条 |
| 异常样本剔除 | 零互动视频、违规下架视频、纯广告无内容视频 |

## 五、公开范围的边界说明（重要）

1. **原始评论语料未公开。** 语料采集自抖音公开平台，内容涉及大量普通用户的评论数据，受平台数据政策与个人信息保护要求约束，未随本仓库一并发布。
2. **示例数据非论文数据。** `code/data/sample_videos.csv` 与 `code/data/sample_comments.csv` 是**同字段结构的构造数据**，仅用于验证代码可运行、流程可跑通。其数值与论文的 406 条样本**没有任何关系**，请勿将其作为论文数据的替代或引用来源。
3. **示例词典为片段。** `code/data/lexicon_*.txt` 收录论文明确列举的示例词条并做了必要的同义扩充，规模远小于研究实际使用的词典，不用于复算论文结论。
4. **可复算的部分。** 论文表 4-1 ~ 表 4-3 的全部数值已完整导出至 [`../tables/`](../tables)（Markdown + CSV），可直接用于核对、绘图与二次分析。
