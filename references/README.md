# 引用与参考文献

本目录收录论文参考文献的三种呈现形式：

| 文件 | 说明 |
| --- | --- |
| [`references.md`](./references.md) | 与论文正文「参考文献」章节逐字一致的可读列表 |
| [`references.bib`](./references.bib) | BibTeX 格式，可直接被 LaTeX / Zotero / EndNote 导入 |
| [`references.json`](./references.json) | JSON 数组，便于程序化处理 |

## 重要说明

参考文献条目**严格按论文原稿转录**，未对其著录信息做任何增补、勘误或改写。原稿中条目格式混用了「。」与「.」两种分隔符，以圆括号标注期号，均为原文风貌，本目录予以保留。

如需在正式投稿场景使用，建议对照原刊核对卷号、期号、页码与 DOI 等信息。
